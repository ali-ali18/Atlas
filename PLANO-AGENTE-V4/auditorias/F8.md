## Aceitos
| Item | Motivo |
|---|---|
| `paid` ainda sai de texto/URL da página (`PAID_TEXT`, `PAID_URL`) e o desafio (3DS, captcha, app do banco) de texto/URL de quadro | A auditoria pediu para tirar só a recusa. "Pago" não repete clique (a trava vale), mas a regra 60-agente prefere sinal estrutural: fica como pendência de uma rodada futura. |
| `git log -p` sem caminho pode mostrar um `.env` que já foi commitado | Sem caminho não há argumento para julgar; `.env` costuma estar no `.gitignore`. A saída ainda passa por `redactSecrets`. |
| Registrable domain aproximado (sem a lista pública de sufixos) | Na dúvida o domínio fica maior, o que só deixa a regra mais estrita. |
| Form de busca (GET) agora exige `intent: submit` | É o preço de não depender de `action`/`method`: o modelo declara o intent e o dono só é consultado nos efeitos que pedem. |
| CapDrop de VM antiga só é corrigido quando ela é recriada | `docker update` não muda capacidades; recriar no meio do uso perde a sessão. O log avisa. |
| `--no-sandbox` do Chrome | O container (CapDrop, limite de processos e memória, proxy de saída) segura o risco; Chrome sandboxed pede userns/seccomp que a imagem não traz. |

## Fora do escopo (só anotado)
